# LowBite

YouTube(Shorts 포함) 영상 링크의 레시피를 AI로 분석해 저칼로리, 키토, 비건 등 원하는 식단으로 바꿔 주는 웹 서비스입니다.

> ⚠️ OpenAI API 사용 비용 문제로 현재 서비스 운영을 중단했습니다.

## 주요 기능
- Google 로그인 (Firebase Authentication)
- 영상 링크에서 레시피 추출 및 식단별 변환
- 변환 전후 영양 성분 비교
- 재료 장바구니, 레시피 저장, 요리 일기
- 식단 목표와 알레르기 설정 화면

## 동작 흐름
1. YouTube 링크를 입력하면 서버가 영상 설명과 인기 댓글을 가져옵니다.
2. OpenAI(GPT-4o)가 재료와 조리 단계를 추출하고, 선택한 식단(저칼로리, 키토 등)에 맞는 대체 재료로 변환합니다.
3. 재료 이름을 영어로 번역한 뒤 USDA FoodData Central에서 영양 성분을 조회해, 원본과 다이어트 버전의 칼로리와 영양소를 계산합니다.
4. 결과를 비교해 보여주고, 저장한 레시피와 요리 기록은 Firestore에 사용자별로 저장합니다.

## 구현하면서 신경 쓴 점
- 단위 정규화: "큰술", "한 줌", "약간" 같은 비정형 단위를 g/ml 기준으로 바꾸는 매핑 테이블을 만들어 칼로리 계산 정확도를 높였습니다.
- 1인분 기준 통일: 모든 재료량을 1인분으로 환산해 원본과 다이어트 레시피를 같은 기준으로 비교합니다.
- 한글 재료명 처리: 한글 재료명은 영어로 번역한 뒤 USDA에서 검색합니다.

## Tech Stack
HTML · JavaScript · Node.js (Express) · Firebase (Auth, Firestore) · OpenAI API · YouTube Data API · USDA FoodData Central · Vercel
